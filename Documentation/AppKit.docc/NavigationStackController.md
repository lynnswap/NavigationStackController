# ``NavigationStackController``

Navigate through a history of AppKit view controllers.

## Overview

`NavigationStackController` contains `NSViewController` pages and supports interactive trackpad navigation.

Requires Swift 6.3 or later and macOS 15.4 or later. Use the controller and its delegate on the main actor.

Start with <doc:AppKitIntegration> to host the controller in your application.
